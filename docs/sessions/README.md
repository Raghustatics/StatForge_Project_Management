# Session Logs

- **One file per working session:** `YYYY-MM-DD_HHMM_Gxx.md` (AGENTS.md §15).
- Written by the agent at the end of each session, and at once when something goes wrong.
- Never contains secrets, API keys, dataset contents, personal data or Altius information.

## Template

```
# Session YYYY-MM-DD HH:MM · Gxx <name>

- Goal:
- Done: (tasks, files changed)
- Commands and results: (summarised)
- Problems: symptom → root cause → fix → guarding test
- Decisions and questions: (link DECISIONS entries)
- Skills and agents used:
- ci-check branches pushed/deleted: (if any)
- Open items:
- Next step:
```
